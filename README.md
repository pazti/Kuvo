# Kuvo

**A modern messaging platform built for young Nigerians.**

Kuvo starts on campuses, grows into a national messaging app, and later powers business messaging — priced in naira and owned in Nigeria.

## Vision

Own the communication layer for the next generation of Nigerians — starting where they already gather (campuses), then expanding to cities and businesses.

## Current Status

- Strategy locked: Campus-first → Young Nigeria → Business
- Name locked: **Kuvo**
- Design direction: Clean, energetic, soft-depth modern messaging UI
- Core team roles being assigned
