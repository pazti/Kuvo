# Design System

## Direction

Clean, energetic, modern messaging UI.  
Soft depth + bold accents. Youthful but professional. High contrast and large touch targets.

## Key Principles

- Soft pastel / light backgrounds with gentle depth
- Rounded cards with subtle shadows
- Strong visual hierarchy
- Bold but restrained solid color accents
- Highly scannable list cards
- Clear floating primary CTAs
- Color-coded status tags
- Soft 3D or simple geometric illustrations for empty states

## Typography

Inter (or SF Pro) — SemiBold for headings, Regular/Medium for body.

## Components

- Chat list cards
- Message bubbles
- Primary and secondary buttons
- Status tags
- Bottom navigation
- Floating action button (New Chat)
- Empty states with illustration
