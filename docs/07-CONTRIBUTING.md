# Contributing

## Rules

1. Pick a role and stick to it.
2. Communicate blockers early.
3. Design and product decisions go through the core team.
4. Code and design must follow the established system.
5. No silent inactivity.

## How to Propose Changes

- Open an issue or discuss in the team chat first.
- For design: update Figma and notify.
- For product: update the relevant docs.
