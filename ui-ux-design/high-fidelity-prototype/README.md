# Kuvo High-Fidelity Mobile Prototype

This is the imported React/Vite prototype for Kuvo's first mobile experience.

## Included flows

- Onboarding
- Chat list
- One-to-one chat
- Group chat
- Contacts
- Status
- Profile
- Settings
- New chat

## Run locally

From this directory:

```bash
pnpm install
pnpm dev
```

The prototype is a visual and interaction reference. It does not include production authentication, messaging, persistence, push notifications, or backend services.
