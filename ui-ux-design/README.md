## Direction

Kuvo should feel energetic and unmistakable without making messaging harder to use. The proposed direction keeps the prototype's clear mobile hierarchy and adds controlled neo-brutalist signals:

- solid, high-contrast color blocks
- confident black outlines
- small hard-offset shadows on key actions
- expressive typography for identity moments
- restrained decoration in message-heavy screens

Neo-brutalism is an identity layer, not an excuse to make every screen loud.
